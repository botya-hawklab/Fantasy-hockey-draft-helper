Fantasy Hockey Draft Coach

A personal fantasy hockey draft analysis and recommendation project.

About the Project

Fantasy Hockey Draft Coach is an independent software project currently being developed for personal use and limited testing.

The application is intended to analyze fantasy hockey league settings, roster configuration, player information, and draft activity to provide draft-day player recommendations.

The project is currently in development and is not yet available as a public consumer application.

Independent project. Not affiliated with or endorsed by Yahoo or the NHL.
